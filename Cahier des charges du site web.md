# Cahier des charges du site web
# EMP — École des Métiers Professionnels

## Version de travail

Ce document constitue la base fonctionnelle, éditoriale et technique du futur site web de l’EMP — École des Métiers Professionnels. Il sera complété lorsque l’école transmettra son logo, ses photographies, les durées des formations, les conditions d’admission, les tarifs et les informations détaillées de chaque certification.

---

## 1. Présentation du projet

L’EMP est une école de métiers professionnels située à Tivaouane Peulh. Elle propose des formations pratiques dans trois grands domaines : l’hôtellerie, l’informatique et le transport/logistique/commerce international.

Le site web devra présenter l’école de manière professionnelle, moderne et rassurante. Son objectif ne sera pas seulement de communiquer des informations, mais d’aider chaque visiteur à comprendre rapidement :

- ce que l’école propose ;
- quelle formation peut lui correspondre ;
- quelle certification il peut préparer ;
- comment contacter l’école ;
- comment demander des informations ou une bourse ;
- comment démarrer une inscription.

Le site devra être accessible aux élèves, aux parents, aux professionnels et aux partenaires de l’école.

## 4. Objectifs du site

Le site devra :

1. Présenter clairement l’EMP et ses valeurs.
2. Mettre en avant les trois pôles de formation.
3. Permettre à un visiteur de trouver rapidement une formation.
4. Expliquer les certifications proposées.
5. Présenter les débouchés professionnels.
6. Donner confiance aux élèves et aux parents.
7. Faciliter les demandes de renseignements.
8. Permettre une demande de bourse ou de préinscription directement depuis le site, sans rediriger l’utilisateur vers Google Forms.

## 5. Publics cibles

### Élèves et candidats

Ils chercheront une formation, un diplôme, une compétence ou une orientation professionnelle. Ils utiliseront principalement leur téléphone et auront besoin d’informations simples, rapides et visuelles.

### Parents et responsables

Ils chercheront la crédibilité de l’école, les conditions d’admission, les certifications, les coûts, la localisation et les moyens de contacter la direction.

### Adultes en reconversion ou en perfectionnement

Ils chercheront une formation pratique, une durée claire, des compétences directement utiles et des informations sur les horaires ou les modalités d’inscription.

### Entreprises et partenaires

Ils pourront rechercher des profils formés, proposer un partenariat ou contacter l’école pour une collaboration.

## 6. Direction artistique

### Ambiance générale

Le site devra être :

- professionnel ;
- moderne ;
- sérieux sans être froid ;
- accessible aux jeunes ;
- tourné vers les métiers et l’emploi ;
- clair sur mobile ;
- local et authentique.

Il ne devra pas ressembler à un site universitaire générique. L’identité devra évoquer l’apprentissage concret, les ateliers, les outils, les compétences et l’entrée dans la vie professionnelle.

### Palette provisoire

La palette finale sera définie à partir du logo officiel. En attendant, la direction proposée est la suivante :

- Bleu principal : confiance, compétence et sérieux.
- Bleu foncé : titres, navigation et sections institutionnelles.
- Bleu clair : arrière-plans, cartes et éléments pédagogiques.
- Blanc : respiration, lisibilité et contraste.
- Gris très clair : séparation des sections et fonds secondaires.
- Couleur d’accent éventuelle : à choisir après réception du logo. Elle pourra servir uniquement aux boutons, aux indicateurs ou aux éléments importants.

La couleur d’accent ne devra pas concurrencer le bleu comme couleur principale de l’école.

### Style des images

Les images devront privilégier :

- les étudiants en situation réelle ;
- les ateliers de cuisine et de pâtisserie ;
- les ordinateurs et travaux numériques ;
- la création graphique et le marketing digital ;
- le transport, la logistique et les échanges commerciaux ;
- les enseignants et l’accompagnement ;
- les locaux réels de l’EMP.

Les images de banque génériques devront être limitées. Les photos réelles de l’école augmenteront fortement la confiance.

## 9. Bouton WhatsApp flottant

Cette fonctionnalité est obligatoire dans le cahier des charges.

### Fonctionnement

Un bouton WhatsApp devra être visible sur toutes les pages du site, notamment sur mobile. Il restera positionné dans un coin de l’écran pendant le défilement.

Lorsqu’un visiteur clique dessus, son téléphone ouvrira automatiquement WhatsApp avec une conversation vers le numéro officiel de l’école :

**70 785 15 55**

Lien cible :

`https://wa.me/221707851555`

### Message prérempli recommandé

Le bouton pourra ouvrir WhatsApp avec un message déjà écrit :

> Bonjour EMP, je souhaite obtenir des informations sur vos formations et les conditions d’inscription.

Ce message facilitera le premier contact tout en laissant l’élève le modifier avant l’envoi.

### Présentation

Le bouton devra :

- être facilement reconnaissable ;
- rester suffisamment petit pour ne pas cacher le contenu ;
- être accessible sur téléphone et ordinateur ;
- comporter un texte au survol sur ordinateur ;
- avoir un texte alternatif pour les lecteurs d’écran ;
- ne pas empêcher l’utilisation des autres boutons.

Une animation légère peut attirer l’attention lors de la première visite, mais elle devra respecter les utilisateurs qui préfèrent réduire les animations.

### Message selon la page

Une version évoluée pourra adapter le message :

- depuis Hôtellerie : “Bonjour, je souhaite des informations sur les formations en hôtellerie.”
- depuis Informatique : “Bonjour, je souhaite des informations sur les formations en informatique.”
- depuis Transport : “Bonjour, je souhaite des informations sur le transit, la logistique et le commerce international.”

## 10. Formulaire intégré de demande

Le site ne devra pas utiliser Google Forms comme interface principale. Le formulaire sera directement intégré au site EMP.

### Champs prévus

- Prénom
- Nom
- Adresse email
- Numéro de téléphone
- Niveau scolaire actuel
- Filière souhaitée
- Niveau ou certification souhaité : CS, BT, BEP ou BTS
- Message facultatif
- Case d’acceptation de la politique de confidentialité

### Fonctionnement

Après envoi :

1. Le site vérifie que les champs obligatoires sont correctement remplis.
2. La demande est transmise automatiquement à l’adresse email officielle de l’école.
3. L’élève reçoit un message de confirmation sur le site.
4. L’équipe peut répondre par email ou WhatsApp.
5. La demande pourra être enregistrée dans une base de données si cette option est activée.

### Email de réception

Objet recommandé :

`Nouvelle demande EMP — [Prénom Nom]`

Le message devra contenir toutes les informations saisies et la date de la demande.

L’adresse de réception sera ajoutée après création de l’email officiel de l’école.

### Protection

Le formulaire devra prévoir :

- validation des champs ;
- protection anti-spam ;
- limitation des soumissions abusives ;
- message d’erreur compréhensible ;
- confirmation après envoi ;
- protection des données personnelles.

## 14. Exigences techniques

### Interface

Le site pourra être développé avec une architecture moderne basée sur React ou Vue.js. Une implémentation Next.js est recommandée si l’école souhaite un bon référencement et des pages rapides.

### Serveur et données

Pour les demandes, les formations et les contenus administrables, les options possibles sont :

- Node.js avec Express ;
- PHP/Laravel ;
- MySQL ou MongoDB selon la structure retenue.

Pour une première version simple, le formulaire peut envoyer les demandes vers l’email officiel sans créer immédiatement un espace étudiant. Une base de données pourra être ajoutée lorsque le volume de candidatures augmentera.

### Responsive design

Le site devra être testé sur :

- téléphone mobile ;
- tablette ;
- ordinateur portable ;
- grand écran.

La priorité sera donnée à l’expérience mobile, car les élèves utiliseront probablement leur téléphone pour consulter le site et contacter l’école sur WhatsApp.

### Référencement

Chaque page devra avoir :

- un titre clair ;
- une description ;
- une adresse web lisible ;
- des titres hiérarchisés ;
- des images avec texte alternatif ;
- des contenus utiles sur les formations ;
- une page Contact correctement renseignée ;
- une configuration de partage sur les réseaux sociaux.

### Sécurité

Le site devra utiliser HTTPS et protéger les données transmises par les formulaires. Les informations des élèves ne devront pas être affichées publiquement.
